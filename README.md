# NOS VEMOS MAÑANA

## Descripción

Nos Vemos Mañana es un videojuego 2D de aventura narrativa y misterio.
El jugador experimenta su primer día de universidad, donde situaciones
cotidianas como llegar tarde, perderse, enfrentarse a profesores y cumplir
con actividades académicas comienzan a transformarse en situaciones extrañas.

Al finalizar el día, el protagonista despierta nuevamente a las 6:30 a.m.,
descubriendo que el primer día se repite. El jugador deberá explorar,
resolver situaciones y descubrir pistas para comprender el origen del ciclo
y conseguir llegar al verdadero "mañana".

## Estructura del proyecto

Las principales carpetas del proyecto son:

- `Assets/Scenes` — Escenas del videojuego.
- `Assets/Sprites` — Imágenes y sprites utilizados en el proyecto.
- `Assets/Settings` — Configuraciones del proyecto.
- `Packages` — Paquetes utilizados por Unity.
- `ProjectSettings` — Configuraciones generales del proyecto.

## Ejecución

### Instrucciones para abrir el proyecto en Unity

1. Clonar el repositorio desde GitHub.
2. Abrir Unity Hub.
3. Seleccionar la opción para agregar un proyecto existente.
4. Seleccionar la carpeta `universidad-2d`.
5. Abrir el proyecto utilizando la versión de Unity utilizada por el equipo.

## Assets

Los assets utilizados en el proyecto corresponden a recursos propios utilizados con fines académicos.


## Flujo de trabajo

El proyecto utiliza un flujo de trabajo basado en Git:

- `main` — Rama correspondiente a la versión estable del proyecto.
- `develop` — Rama principal de desarrollo.
- `feature/*` — Ramas utilizadas para desarrollar tareas específicas.

Los cambios se realizan en ramas `feature/*`, posteriormente se integran
en `develop` y finalmente pueden incorporarse a `main`.
