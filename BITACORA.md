# Bitácora del proyecto: universidad-2d

Responsable del registro: Daniel Gustavo Zambrana Rondón.

## 03/09/2026

### Actividades realizadas

- Se creó el repositorio público universidad-2d en GitHub.
- Se incorporó la estructura inicial del proyecto, con las carpetas Assets, Packages y ProjectSettings.
- Se agregó el archivo .gitignore al repositorio.
- Se establecieron las ramas main y develop.

### Problemas encontrados

- Confusión al distribuir las tareas, algunos integrantes no tenían claro qué actividad debían realizar.
- Desorganización de los archivos, los recursos estaban mezclados y resultaba difícil encontrarlos.
- Dificultad para acceder como colaborador, un integrante podía ver el repositorio, pero no modificarlo.
- Los cambios locales no aparecían en GitHub, se había realizado el commit, pero faltaba enviarlo al repositorio.
- La copia local estaba desactualizada, no aparecían los últimos cambios de los compañeros.
- Se cortaron mal los sprites

### Soluciones aplicadas

- Se repartieron las responsabilidades y se definió quién trabajaría en el escenario, los recursos gráficos y la documentación.
- Se organizaron los archivos dentro de Assets, utilizando carpetas para fondos, personajes, tiles y escenas.
- Se revisó la invitación y el integrante la aceptó desde su propia cuenta de GitHub.
- Se utilizó Push origin y se comprobó que el commit apareciera en la rama correspondiente de GitHub.
- Se seleccionó la rama correspondiente y se utilizaron Fetch origin y Pull origin para actualizarla.
- Se volvio a cortar correctamente los Sprites
